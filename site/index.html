Features

  • Systems: Game Boy Advance, Game Boy, Game Boy Color, NES, SNES, Nintendo 64, Mega Drive, Master System, Game Gear, Dreamcast, PC Engine, PlayStation, PSP, Arcade, Neo Geo Pocket, WonderSwan, Atari 2600 and Atari Lynx.
  • Deep sleep: about 0.6% battery drain per hour, so it can last for days.
  • Hardware video decoding for H.264, H.265, VP8, VP9 and MPEG-2.
  • Box art packs for game lists.
