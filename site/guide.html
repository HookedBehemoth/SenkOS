Install

  1. Download the RG35XX SP image.
  2. Flash it to a microSD card with balenaEtcher or Raspberry Pi Imager on Windows, macOS or Linux. Select the downloaded image and your card. On Linux, you can also run: 
    gunzip -c senkos-image.wic.gz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
    Replace /dev/sdX with your SD card device.
  3. Put the card in TF1 and boot the handheld.

Games and saves

Connect the running handheld to your computer by USB-C. On Windows, open RG35XX-SP → Main card in File Explorer (handheld: Settings → Storage → USB connection → MTP). On macOS or Linux, select SMB in Storage and connect to smb://10.55.0.1/Main%20card. In Main card, create a ROM folder if needed; GBA games go in roms/gba/.

FolderContents
roms/<system>/ROMs
OS/assets/emulator/BIOS files
OS/saves/<core>/Saves and save states

To import a save, put a matching .srm or .sav next to the ROM before playing it. SenkOS reads that file and writes later changes to OS/saves/<core>/. Back up both locations if you imported a save.

Add systems and emulators

Built-in systems only need a ROM folder. To add an emulator, put a Linux ARM64 libretro core at apps/emulators/my-core/my-core_libretro.so and create apps/emulators/my-core.desktop:

[Desktop Entry]
Type=Application
Name=My GBA core
Exec=corehost /data/apps/emulators/my-core/my-core_libretro.so %f
MimeType=application/x-gba-rom;

This adds an emulator to Game Boy Advance. Press Select on a game to switch emulators.

Add a system

Create apps/systems/example.system:

[System]
Name=Example Console
Folder=roms/example
Patterns=*.rom;*.zip;
MimeType=application/x-example-rom;

Create roms/example/ and an emulator entry like the one above, using MimeType=application/x-example-rom; in both files. Set Exec to a compatible core or native emulator; %f passes it the ROM. Restart after adding a system.

Add a native app or game

Copy a Linux ARM64 program to apps/applications/my-game/game and create apps/applications/my-game.desktop:

[Desktop Entry]
Type=Application
Name=My Game
Exec=/data/apps/applications/my-game/game
Path=/data/apps/applications/my-game

It appears under Applications.

Replace the splash screen

Choose an image and background color in the splash screen maker. Power off the handheld and put its TF1 card in your computer. Extract the download onto the boot partition, then put the card back and boot.
